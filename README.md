# 📋 Planificador APP | Full-Stack Web Application

> **Estado del proyecto:** 🚧 En desarrollo

## 📖 Descripción

**Planificador APP** es una aplicación web Full-Stack diseñada para ayudar a los usuarios a organizar y gestionar sus tareas de manera sencilla, intuitiva y eficiente.

El proyecto busca ofrecer una experiencia interactiva para la administración de tareas, permitiendo crear, consultar, actualizar y eliminar actividades, además de facilitar el seguimiento de su estado.

Este proyecto forma parte de mi proceso de formación como desarrolladora Full-Stack y tiene como objetivo integrar conocimientos de desarrollo Front-End y Back-End en una aplicación completa.

---

## 🎯 Objetivos

* Desarrollar una aplicación Full-Stack desde cero.
* Implementar una interfaz moderna, intuitiva y responsive.
* Consumir APIs para la comunicación entre Front-End y Back-End.
* Construir una API REST utilizando Java y Spring Boot.
* Persistir la información en una base de datos relacional.
* Aplicar operaciones CRUD siguiendo buenas prácticas de desarrollo.
